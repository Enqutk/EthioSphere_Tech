# Contributing

Thanks for your interest in Programmers World.

## Commit messages

Use [Conventional Commits](https://www.conventionalcommits.org/):

```
feat: add pagination to project list
fix: handle duplicate like toggle on mobile
docs: update Vercel env checklist
```

Keep the subject line under ~72 characters. Use the body for context when needed — write it yourself; don't paste unedited AI-generated essays.
